# 验收标准模板（ac-template）

> 由 `un-acceptance-criteria` 生成，路径建议 `.sdlc/AC.md`。每条 AC 必须可验证、可自动化。

## 验收标准（AC）
- AC-1（关联 FR-1，优先级 P0）
  - Given <前置上下文>
  - When <触发动作>
  - Then <可观察结果>
- AC-2 ...

## 完成定义（DoD）
- [ ] 功能按 AC 全部通过
- [ ] 有对应单元测试且通过
- [ ] 代码已评审
- [ ] 文档/注释更新
- [ ] 无阻断级缺陷

## 非功能验收
- 性能指标如何测量
- 兼容性矩阵
